# mathandcode.com

Build with `md2html`. Run `make serve` for a local preview.

- `_layouts/` and `_includes/` contain the page HTML.
- `css/main.css` styles the shared site layout and defines the theme colors used by md2html.
- `css/articles.css` sets typography for ordinary pages.
- `css/md2html.css` sets code fonts and compact tables of contents. md2html supplies the code-box, highlighting, and math styles.
- `css/sicp.css` styles the SICP notes separately.
- `js/site.js` saves reader preferences. Layout, reader controls, code boxes, and pre-rendered math work without JavaScript.

Build and rendering options are in `md2html.json`.
